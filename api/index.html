No API key is needed. Use set=fra, hob or msh and count=50 or 100. Add a new nonce value if your chat tool reuses a previous response.

  
Selection uses the same rarity weights as Drill with reset memory. Only rated cards are included. Cards may repeat later in the batch, but never twice in a row. Your browser's mistake history is not included; API clients can supply history with POST.
